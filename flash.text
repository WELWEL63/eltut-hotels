These patterns are already established. DO NOT deviate.

10. Validators run BEFORE Mongo (testable without live connection)
11. Aggregations use pipelines, never read-modify-write
12. Counter updates use atomic $inc / $push / $pull
13. ensure_indexes() graceful — returns False if Mongo not ready
14. TTL indexes for automatic expiry — no cron
15. Booking creation = one transaction across 5 tables
16. Money always Decimal, never float
17. Half-open interval overlap for hotel availability
18. Filters item_type='primary' so add-ons don't count toward
